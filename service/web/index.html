How it works

Three keys and your voice. No copying screenshots into a chat window.

Hold Ctrl + Alt + Space

Anywhere, in any application. Nimbus listens while you hold it and stops when you let go.

Ask in plain words

“What does this setting do?” “Why is this render failing?” “Where do I export from here?”

It answers and points

You hear the answer, and your pointer flies to the button, menu or field it means.

Built for the software nobody wrote a tutorial for

Nimbus already knows mainstream tools. For the rest — an in-house system, a lab instrument's control panel, a plugin with no documentation — you drop your notes in a folder and it reads them.

Teaching mode

It draws on the screen

Boxes round the control you need, everything else dimmed, numbered steps for a sequence, and an arrow from the mistake to the fix.

Remembers

Per-application memory

What you asked in one program stays with that program, as plain Markdown files you can read, edit or delete.

Reviews

Quiz me

Say “quiz me” and Nimbus asks you back — against your live screen, which a flashcard app cannot do.

Works offline

Fully local option

Run the model, speech recognition and voice entirely on your machine. Nothing leaves it, and no API key is needed.

Privacy, stated plainly

  • Privacy Guard is on by default. When a password manager, sign-in page or other sensitive window is in front, Nimbus answers without taking a screenshot — and the app shows you how many times it has done that.
  • Your API keys stay on your machine, in Windows Credential Manager. Nimbus has no server that sees them.
  • Screen contents go only to the model provider you chose, and not at all on the fully-local setup.
  • The chat panel is excluded from screen capture, so your conversation cannot end up in a screenshot or a screen share.

The only thing this site stores about your computer is a salted hash used to count your devices. Never a raw hardware identifier.
